# Pharmaceutical Supply Chain Traceability System

## Overview
This project implements a blockchain-based pharmaceutical supply chain tracking system using Ethereum. It ensures transparency, traceability, and authenticity verification of drug batches.

## Features
- Drug batch registration by manufacturers
- Ownership transfer between supply chain participants
- Verification by pharmacies
- Immutable audit trail using blockchain events
- IPFS integration for off-chain document storage

## Tech Stack
- Solidity (Smart Contracts)
- Ethereum (Sepolia Testnet)
- Hardhat
- React.js
- Web3.js / ethers.js
- IPFS
- MetaMask
